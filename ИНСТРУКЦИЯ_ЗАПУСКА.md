# Инструкция: Запуск хлопания робота G1 на сервере

## Что будет происходить

Робот G1 будет **стоять на месте** и **хлопать в ладоши** в цикле:

1. **Цикл хлопания** — 4 секунды:
   - 0–1 сек: руки открываются
   - 1–2 сек: руки закрываются → **ХЛОПОК!**
   - 2–3 сек: руки открываются
   - 3–4 сек: возврат в исходное положение

2. **После завершения цикла** — новый цикл начинается сразу же

3. **Вы увидите**:
   - В консоли (логи): каждый цикл выводится информация о фазе хлопания
   - В Isaac Sim (видео): робот стоит в одном месте, руки движутся синхронно

## Если что-то пошло не так

### 1. "observation dimension (0) ≠ 994" в логах

**Проблема:** sim-ros2-bridge не запустился

**Решение:**
```bash
docker compose ps | grep ros2-bridge
# Если его нет, перезагрузитесь:
docker compose down
docker compose up -d
```

### 2. Робот не движется / видео не загружается

**Решение:**
- Подождите еще 1–2 минуты (Isaac Sim долго загружается)
- Проверьте логи Isaac Sim:
  ```bash
  docker logs wam-isaac-sim | tail -20
  ```

### 3. "Could not connect to localhost:6081"

**Решение:**
```bash
# На локальном ПК, убейте старый SSH туннель
killall ssh

# Запустите новый
ssh -N -L 6081:localhost:6080 -p 2221 x32-techgov-GPU-01

# Откройте браузер
```

### 4. Хотите остановить стек

```bash
# На сервере в терминале 1
docker compose down

# Все контейнеры остановятся
```
